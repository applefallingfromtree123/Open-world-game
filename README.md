# NEON//VOID — 사이버펑크 오픈월드 우주 MMO

브라우저에서 바로 플레이하는 **실시간 멀티플레이어 3D 오픈월드 우주 게임**입니다 (Three.js + WebGL).
EVE Online에서 영감을 받은 샌드박스 경제·클랜 전쟁에, 네온과 글리치로 가득한 사이버펑크 분위기를 섞었습니다.

## 주요 기능

| 분류 | 내용 |
|---|---|
| 🎮 **풀 3D 그래픽** | Three.js WebGL — 3D 함선 모델(네온 엣지), 조명받는 행성·대기·고리, 회전하는 스테이션, 입체 소행성대, 절차적 성운 스카이박스, 블룸 후처리, 워프 스트릭, 3D 폭발 파티클, 자유 회전 카메라 |
| 🌌 **거대한 오픈월드** | 반경 650,000 유닛의 은하, 16개 성계, 40여 개 스테이션, 1,000개 이상의 소행성, 공전하는 행성들 |
| 🚀 **직접 비행 + 워프** | 행성 간 이동은 텔레포트가 아니라 우주선으로 직접 비행. 워프 드라이브(충전 → 초고속 비행), 항성 중력장에서 강제 이탈, 충전 중 피격 시 취소 |
| 🛸 **10종 우주선** | 셔틀 · 인터셉터 · 채굴선 · 화물선 · 전투기 · 봉쇄돌파선 · 프리깃 · 대형 채굴선 · 구축함 · 순양함 — 기종별 속도/워프/화물/무기/채굴력이 다름 |
| 💰 **게임 내 재화(¢ 크레딧)** | 채굴, 스테이션 간 무역(재고에 따른 실시간 시세), 임무, 해적 현상금, 탐험, 성계 발견 보너스 |
| ⚔ **전투** | 펄스 레이저, 플라즈마 블래스터, 스캐터 캐논, 레일건, 유도 미사일. 해적 NPC 7종(스웜 드론 떼, 블랙아이스 건쉽 등) + 널섹 보스 「카이주」 |
| 🤖 **로그 파일럿 봇** | 플레이어와 같은 기체를 모는 적대 AI 30기가 성계 사이를 워프로 이동하며 로우섹·널섹에서 플레이어를 사냥. 로컬 채팅으로 도발, 피해가 크면 도주, 가끔 등장하는 ACE 봇은 구축함·순양함 탑승 |
| 🚓 **보안군** | 하이섹 순찰 NPC — 해적·봇·범죄자(☠)를 공격하고 신규 파일럿을 보호 |
| 🛡 **보안 등급** | 하이섹(PvP 불가) / 로우섹(PvP 가능, 선제공격 시 범죄자 플래그) / 널섹(무법지대) |
| ⚑ **클랜** | 창설·가입(자유/승인제)·간부·추방·리더 위임, 클랜 채팅, 공동 금고, 아군 사격 방지, **널섹 주권 비콘 점령전** |
| ✦ **우주 탐험** | 신호 스캐너(R)로 난파선·밀수 은닉처·고대 유적 탐지 → 해킹(E) → 보상. 유적은 수호자가 깨어남 |
| 💬 **채팅** | 전체 / 지역(성계) / 클랜 / 귓속말(`/w`) / 시스템 킬피드 |
| 📋 **메뉴** | 파일럿 통계, 화물, 임무, 클랜, 랭킹(자산·PvP·사냥·탐험·클랜), 설정(볼륨·그래픽), 도움말 |
| 🗺 **은하 지도** | 확대/이동, 미탐사 성계는 ???로 표시, 더블클릭으로 오토파일럿(자동 워프 + 자동 도킹) |
| 🎧 **사운드** | 외부 파일 없이 WebAudio로 합성한 효과음 + 신스웨이브 앰비언트 음악 |
| 🔒 **서버 권위** | 모든 이동·전투·경제는 서버가 판정. 클라이언트는 예측 + 보간으로 부드럽게 표시 |

## Render 배포

### 방법 A — Blueprint (추천)
1. 이 저장소를 GitHub에 푸시합니다.
2. [Render 대시보드](https://dashboard.render.com) → **New → Blueprint** → 이 저장소 선택.
3. `render.yaml`이 자동으로 인식되어 웹 서비스가 생성됩니다.

### 방법 B — 수동 Web Service
- **Runtime**: Node
- **Build Command**: `npm install`
- **Start Command**: `npm start`
- **Health Check Path**: `/healthz`

포트는 Render가 주는 `PORT` 환경 변수를 자동으로 사용하며, WebSocket(`/ws`)도 같은 포트로 동작합니다.

### 💾 데이터 저장 (Render 무료 서버 슬립 대비)

Render 무료 인스턴스는 15분간 접속이 없으면 잠들고, 다시 깨어날 때 **디스크가 초기화**됩니다. 그래서 세 겹으로 계정을 지킵니다.

| 방법 | 설정 | 보호 범위 |
|---|---|---|
| ① 잠들지 않게 하기 | 자동 (Render가 주는 `RENDER_EXTERNAL_URL`로 10분마다 자기 호출) | 슬립 자체를 막음. 단 재배포·재시작 시엔 디스크 초기화 |
| ② 브라우저 백업 | 자동 | 서버가 서명한 계정 사본을 각 플레이어 브라우저에 보관 → 서버가 초기화돼도 로그인 시 자동 복구 (위조 불가). 같은 브라우저에서만 복구됨 |
| ③ **무료 PostgreSQL (추천)** | `DATABASE_URL` 1개 입력 | 계정·클랜·주권·시장까지 **영구 보존**, 어느 기기에서나 |

**③ Neon 무료 DB 연결 방법 (약 3분)**
1. [neon.tech](https://neon.tech)에 가입 → **Create project** (무료 플랜, 지역은 Singapore 또는 가까운 곳).
2. 대시보드의 **Connection string**을 복사합니다. (`postgresql://...neon.tech/neondb?sslmode=require` 형태)
3. Render 대시보드 → 웹 서비스 → **Environment** → `DATABASE_URL` 에 붙여넣고 저장 → 자동 재배포.
4. Render 로그에 `[db] PostgreSQL 저장소 사용 — 계정이 영구 보존됩니다.` 가 보이면 완료.

Render 자체 PostgreSQL을 써도 되지만 무료 DB는 30일 후 만료되므로 Neon(무료, 만료 없음)을 추천합니다.
서버는 변경 후 5초 이내 + 15초마다 + 종료 시 저장하며, 저장소를 읽지 못하면 빈 세계로 시작하지 않고 재시작합니다(기존 데이터 덮어쓰기 방지).

> keep-alive는 무료 인스턴스 사용 시간(월 750시간)을 거의 다 씁니다. 다른 무료 서비스도 돌린다면 `KEEP_ALIVE=false`로 끌 수 있습니다.

## 환경 변수

| 이름 | 설명 |
|---|---|
| `PORT` | 서버 포트 (Render가 자동 설정, 기본 3000) |
| `DATABASE_URL` | PostgreSQL 연결 문자열 — 설정 시 DB 저장 사용 |
| `PGSSL` | `false`로 설정하면 DB SSL 비활성화 (로컬 PostgreSQL용) |
| `DATA_DIR` | 파일 저장 경로 (기본 `./data`) |
| `SAVE_SECRET` | 브라우저 백업 서명 키 (없으면 Render 서비스 ID로 자동 대체) |
| `KEEP_ALIVE` | `false`면 슬립 방지 자기 호출 끄기 |
| `BOT_COUNT` | 로그 파일럿 봇 수 (기본 30, 0이면 비활성) |

## 구조

```
server/
  index.js   HTTP 정적 서버 + WebSocket + 20Hz 고정 틱 루프 + 자동 저장
  game.js    권위 시뮬레이션: 비행/워프/전투/NPC AI/채굴/해킹/시장/임무/클랜/주권/채팅
  world.js   시드 기반 은하 생성 (성계·행성·스테이션·소행성대·주권 비콘)
  db.js      저장소 (PostgreSQL 또는 JSON 파일)
public/
  index.html, css/style.css   사이버펑크 UI
  shared/    서버·클라이언트 공용 데이터(함선/무기/상품)와 물리 코드
  js/        클라이언트: 네트워크·예측(main), 3D 렌더러(render, Three.js), 함선 윤곽(shapes), HUD·창(ui), 은하 지도(map), 합성 사운드(audio)

Three.js는 CDN이 아니라 `node_modules/three`에서 서버가 직접 `/vendor/three/`로 제공합니다.
게임 판정(이동·충돌·전투)은 은하 평면 위에서 서버가 권위적으로 처리하고, 클라이언트는 이를 3D 공간으로 표현합니다.
```
