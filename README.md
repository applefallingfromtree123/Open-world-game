# STARDRIFT — 오픈월드 3D 우주 샌드박스

브라우저에서 바로 플레이하는 **6자유도(6DOF) 3D 우주 비행 샌드박스**입니다 (Three.js + WebGL).
정해진 길은 없습니다. 무역상, 광부, 현상금 사냥꾼, 해적, 탐험가, 기지 건설자 — 무엇이 될지는 당신이 정합니다.

> 이전 버전(NEON//VOID, 2D 평면 판정 MMO)을 완전히 새로 만든 게임입니다. 이전 서버 데이터는 지워지지 않고 `legacy` 항목으로 보존됩니다.

## 주요 특징

| 분류 | 내용 |
|---|---|
| 🚀 **진짜 3D 비행** | 피치·요·롤 + 전후·좌우·상하 이동의 6자유도. 비행 보조(FA) ON/OFF로 아케이드 ↔ 뉴턴 관성 비행 전환. 부스트, 크루즈 드라이브(성계 내 초고속, 목표 자동 감속), 하이퍼점프(성계 간) |
| 🛸 **고품질 절차적 함선 8종** | 스패로 · 케스트렐 · 프로스펙터 · 아틀라스 · 맨티스 · 노매드 · 뱅가드 · 리바이어던. PBR 금속/클리어코트 도장, 패널 라인·리벳 텍스처, 유리 캐노피, 엔진 화염 셰이더, 깜빡이는 항법등, 포탑. 도색 커스터마이즈 |
| 🌌 **36개 성계의 은하** | 시드 기반 생성. 성계마다 항성(7종 분광형), 3~7개 행성(용암·사막·암석·해양·생명·독성·얼음·가스 거성 3종, 위성, 고리), 스테이션 3종 디자인, 소행성대, 절차적 성운 하늘 |
| 🤖 **살아있는 생태계** | 상선은 스테이션 사이를 오가며 무역하고, 광부는 소행성을 캐고, 해적은 사냥하고, 보안군은 순찰하며 범죄에 대응. 현상금 사냥꾼은 수배자를 추적. 모두 같은 물리로 비행하는 자율 AI |
| 💰 **동적 경제** | 스테이션 유형별 생산/수요, 재고에 따른 실시간 시세 변동. 불법품은 해적 소굴에서만 — 보안군 스캔에 걸리면 압수와 벌금 |
| ⚔ **전투** | 펄스 레이저 · 멀티캐논 · 플라즈마 · 레일건 · 유도 미사일 · 채굴 레이저 (S/M/L 크기). 실드/선체 피해 배율, 짐벌 리드 보정, ECM, 3D 폭발·잔해 |
| ⛏ **채굴** | 채굴 레이저로 소행성을 깎아 광석 수집. 보안이 낮을수록 귀한 광물(백금 · 페인석 · 공허 수정) |
| ✦ **탐험** | 행성·항성 근접 스캔 → 탐사 데이터 판매. 신호원(난파선 · 해적 은닉처 · 조난 신호 · 고대 유적 · 교전 지역 · 해적 수송대). 성계 **최초 발견자**가 서버에 기록됨 |
| 📋 **임무** | 배송 · 데이터 운송 · 조달 · 현상금 · 해적 소탕 · 탐사 · 밀수 · 청부 |
| ⚑ **세력 · 평판 · 범죄** | 태양 연합 · 자유 행성 동맹 · 코어 신디케이트 · 붉은 송곳니(해적). 무고한 함선 공격 시 수배 → 보안군·사냥꾼 추격, 도킹 거부. 해적과 친해지면 해적이 공격하지 않음 |
| 🏠 **개인 기지** | 키트를 사서 우주 어디에든 건설. 정제소(시간당 수익, 오프라인 누적), 격납고, 방어 포탑, 교역소, 무제한 보관함 |
| 👥 **용병 윙맨** | 군사 요새/해적 소굴에서 고용. 편대 비행, 표적 공격, 점프 동행 |
| 🔧 **함선 커스터마이즈** | 하드포인트 무기 교체, 코어 모듈 5등급(쉴드·추진기·동력로·하이퍼드라이브·장갑), 옵션 슬롯(화물칸·연료탱크·연료 스쿠프·장갑판·쉴드 부스터·정밀 스캐너·정제기·ECM), 다수 함선 보유와 운송 |
| 🌐 **멀티플레이** | 같은 성계의 다른 파일럿이 실시간으로 보임. 전체/성계 채팅, 저보안·무법지대 PvP, 랭킹 |
| 🎧 **사운드** | 외부 파일 없이 WebAudio로 합성한 엔진음·무기·폭발 + 앰비언트 음악 |

## 📱 모바일 플레이

처음 접속하면 **PC / 모바일**을 묻습니다 (메뉴 → 설정 → 조작 기기에서 언제든 변경). 모바일을 고르면:

- 화면 왼쪽 아무 곳이나 눌러 끄는 **가상 조종 스틱** (누른 위치가 중심)
- 오른쪽 **스로틀 슬라이더** (위 100% · 흰 선 0% · 아래 후진), **발사 · 미사일 · 부스트** 버튼, 왼쪽 **롤** 버튼
- 상단 액션 버튼: 크루즈 · 자동 도킹(회수) · 점프 · 표적 · 적 · 스캔(누르고 있기) · 시점 · 관성 · 정지 · 기지
- 은하 지도는 드래그 회전, 두 손가락 확대/축소(또는 ＋/－ 버튼), 탭으로 경로 설정
- 가로 모드 전용, 그래픽 기본값 '낮음' (설정에서 변경 가능)

## 로컬 실행

```bash
npm install
npm start
# http://localhost:3000 — 여러 브라우저 창으로 멀티플레이 테스트 가능
```

서버 없이도 로그인 화면의 **오프라인으로 플레이**로 즐길 수 있습니다 (진행 상황은 브라우저에 저장).

## Render 배포

### 방법 A — Blueprint (추천)
1. 이 저장소를 GitHub에 푸시합니다.
2. [Render 대시보드](https://dashboard.render.com) → **New → Blueprint** → 이 저장소 선택.
3. `render.yaml`이 자동으로 인식되어 웹 서비스가 생성됩니다.

### 방법 B — 수동 Web Service
- **Runtime**: Node · **Build Command**: `npm install` · **Start Command**: `npm start` · **Health Check Path**: `/healthz`

### 💾 데이터 저장

| 방법 | 설정 | 보호 범위 |
|---|---|---|
| ① 잠들지 않게 하기 | 자동 (`RENDER_EXTERNAL_URL`로 10분마다 자기 호출) | 무료 인스턴스 슬립 방지 |
| ② 브라우저 저장 | 자동 | 모든 진행 상황을 브라우저에도 저장 → 서버가 초기화돼도 같은 브라우저에서 로그인하면 복구 |
| ③ **무료 PostgreSQL (추천)** | `DATABASE_URL` 입력 | 계정·저장·최초 발견 기록을 **영구 보존** |

**Neon 무료 DB 연결**: [neon.tech](https://neon.tech) 가입 → 프로젝트 생성 → Connection string 복사 → Render 웹 서비스 **Environment**의 `DATABASE_URL`에 붙여넣기.

## 환경 변수

| 이름 | 설명 |
|---|---|
| `PORT` | 서버 포트 (기본 3000) |
| `DATABASE_URL` | PostgreSQL 연결 문자열 |
| `PGSSL` | `false`면 DB SSL 비활성화 (로컬 PostgreSQL용) |
| `DATA_DIR` | 파일 저장 경로 (기본 `./data`) |
| `KEEP_ALIVE` | `false`면 슬립 방지 자기 호출 끄기 |

## 구조

```
server/
  index.js   HTTP 정적 서버 + WebSocket + 자동 저장
  hub.js     계정(scrypt) · 세이브 동기화 · 같은 성계 위치 중계(10Hz) · 채팅 · 최초 발견 · 랭킹
  db.js      저장소 (PostgreSQL 또는 JSON 파일)
public/js/
  main.js      게임 루프 · 조종 · 카메라 · 도킹 · 하이퍼점프 · 저장
  engine.js    렌더러 · 플로팅 오리진 · 로그 깊이 버퍼 · 블룸/후처리 · 절차적 성운 하늘 · 환경맵
  models.js    절차적 함선/스테이션/행성/항성/소행성 모델과 셰이더
  ship.js      6자유도 비행 물리 · 크루즈 · 피해
  world.js     성계 시뮬레이션 · 전투 · 채굴 · 충돌 · 신호원 · NPC 생태계 감독
  ai.js        NPC 두뇌 (상선 · 광부 · 해적 · 보안군 · 사냥꾼 · 윙맨)
  universe.js  은하 · 성계 절차 생성, 항로 탐색
  state.js     세이브 데이터 · 시장 경제
  missions.js  임무 생성 · 진행
  hud.js       캔버스 HUD (조준선 · 리드 · 브래킷 · 3D 레이더 · 계기)
  ui.js        스테이션 서비스 · 메뉴 · 패널
  hangar.js    도킹 중 3D 격납고
  map.js       3D 은하 지도 · 경로 계획
  fx.js        파티클 · 폭발 · 발사체 · 빔 · 우주 먼지 · 하이퍼스페이스 터널
  net.js       멀티플레이 클라이언트
  audio.js     합성 사운드
```

비행·전투 시뮬레이션은 각 클라이언트에서 수행되고, 서버는 계정·저장·위치 중계를 담당합니다.
은하는 시드 기반이라 모든 플레이어가 같은 우주를 공유합니다. Three.js는 CDN이 아니라 `node_modules/three`에서 서버가 직접 제공합니다.
